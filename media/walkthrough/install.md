# Install the gfix CLI

gitfix depends on the `gfix` CLI to inspect and resolve merge conflicts via the MCP protocol.

## Install options

**Homebrew (macOS / Linux)**

```
brew install ameyypawar/tap/gfix
```

**Direct download**

Grab the latest release from [gfix.space/install](https://gfix.space/install) for your OS and architecture.

## Verify

```
gfix --version
```

Once installed, click **Refresh** in the gitfix panel or start a `git merge` — gitfix will connect automatically.
